## ✨ What is GUEST AI?

**GUEST AI** is a stylish, AI-powered virtual assistant designed to elevate restaurant service. Acting as your digital front-of-house, it engages guests, explains menu items, takes orders (with full customization), and even schedules future pickups—all through seamless, human-like conversations!

---

## 🚀 Key Features

- **Conversational Ordering**: Natural, fluid dialogue with customers—like a real server!
- **Menu Navigation & Recommendations**: Instantly fetch categories, suggest items, and answer questions.
- **Detailed Item Info**: Show descriptions, ingredients, allergens, pricing—instantly.
- **Item Customization**: Modals for choosing options (e.g., milk, toppings, spice level).
- **Live Cart & Order Management**: Sidebar with real-time order summary and confirmation.
- **Order Scheduling**: Let guests order now, pick up or deliver later.
- **Dynamic Welcome Screen**: Engaging intro for every new guest.
- **Responsive & Accessible**: Beautiful on every device, with high-contrast and ARIA support.
- **Modern Dark Theme**: Sleek, professional, and easy on the eyes.
- **Offline Menu Browsing**: IndexedDB caching for fast, reliable access.

## 🛠️ Quickstart

1. **Clone the Repo**
   ```bash
   git clone https://github.com/W3JDev/GuestAI-Intelligent-Virtual-Restaurant-Assistant.git
   cd GuestAI-Intelligent-Virtual-Restaurant-Assistant
   ```

2. **Configure API Key (Required)**
   - Get your [Google Gemini API Key](https://aistudio.google.com/app/apikey).
   - Create a `.env` file in the root:
     ```
     API_KEY=your_gemini_api_key_here
     ```
   - **Never commit your `.env` file!**

3. **Install Dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

4. **Run the App**
   ```bash
   npm start
   # or open index.html directly in your browser (development only)
   ```

## 💬 How to Use

- Start the app—GUEST AI will greet you.
- Ask for menu categories or details ("What desserts do you have?").
- Add items with customizations ("Add a Latte with oat milk").
- Review and edit your live cart.
- Schedule your order for later if you wish.
- Confirm and enjoy a seamless experience!
